# The City of Vey: Chapter Two — The Grandmothers' Dividend

A complete standalone browser-based political-detective adventure. No dependencies, APIs, assets, fees, or backend.

## How to play

Open `index.html` in a normal browser (Safari, Chrome, Firefox), or serve it using GitHub Pages. The ChatGPT in-app file preview may not execute JavaScript.

Choices persist through localStorage in the same browser. **Dossier** exports a human-readable text record and **Export JSON save** downloads the full game state. **Import** can load a Chronicle 002 save or the original completed Chronicle 001 JSON **before** making any Chapter Two choices. The user's Chronicle 001 outcome, The Price of Improvement, is embedded as the default.

## Publishing alongside Chapter One on GitHub Pages

Upload this folder to `chapters/02-grandmothers-dividend/index.html` in the same public GitHub repository as Chapter One. If GitHub Pages publishes from the main branch root, the expected story path would be:

`https://tofumeows.github.io/the-last-useless-man/chapters/02-grandmothers-dividend/`

This URL is an **expected location**, not a verified live link until the repository is published and its Pages settings are enabled.
