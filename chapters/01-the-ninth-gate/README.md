# The Ministry of Small Affairs — Chapter One: The Ninth Gate

A standalone, offline-first political detective RPG set at the beginning of Vey’s industrial transformation.

## Play

Open `index.html` in a standard browser, or host it with GitHub Pages. All HTML, styles, story content and JavaScript are contained in this file. No API keys, assets, libraries, tracking or build steps.

## Decisions and continuity

- Each choice is automatically saved in the current browser using `localStorage`.
- Use **Case dossier** to copy a readable decision report back into ChatGPT.
- Use **Download transferable save .json** to save the exact game state for future chapters or move between devices.
- Use **Import save** to restore a saved JSON file (paste its full contents).
- Resetting starts a fresh run; export first if you want to compare timelines.

## Publish with GitHub Pages

Upload `index.html` and `README.md` to the root of a public repository's `main` branch. In the repository, open Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save. The live game will appear at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` once GitHub completes deployment.

## Design principles

- Good governance has competing goals; no single meter is a morality meter.
- Technology has prerequisites, tradeoffs, and human consequences.
- Institutions are made of people who have interests and good reasons, not labels.
- One playable chronicle is a civic history, not a universal correct answer.
- The original `The Last Useless Man` is set in a possible much later era of this setting. This chapter predates it by generations.

Not an educational simulation of real hydraulic engineering, medicine, or public administration. All setting details are fictional.
