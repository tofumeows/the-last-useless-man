# The City of Vey · Chronicle 003: The Price of Tomorrow

A self-contained, offline, interactive political detective story. This chapter inherits **The Empty Purse** and the exact final ledger from the user's Chronicle 002 by default. Paste the actual complete Chronicle 002 JSON in **Import** on the opening screen to carry a different saved history. Choices auto-save in this browser; export JSON to make a durable copy.

## Publishing in an existing GitHub Pages repository

Upload `index.html` to `chapters/03-price-of-tomorrow/index.html` inside `tofumeows/the-last-useless-man` and commit it. After GitHub Pages is enabled for the `main` branch/root, navigate to:

`https://tofumeows.github.io/the-last-useless-man/chapters/03-price-of-tomorrow/`

The address is a target path, not evidence that Pages is currently enabled. No external scripts, fonts, images, APIs, accounts, or hosting costs are required beyond hosting a static file.

## Play mechanics

- Six optional investigation leads, five required before convening the hearing; one interruption after the third completed lead
- Budget financing, collection, public investment, transparency, and long-term institutional choices
- Lasting stats, hidden liability and fragility scores, adaptive consequences, multiple endings
- In-browser auto-save, manual JSON import/export, human-readable case dossier
- Import completed Chronicle 002 (`v:2`) or a Chronicle 003 save (`v:3`)

This is fiction, not an economics model. Metrics and consequences are deliberately stylized. The larger City of Vey canon and character names remain original creative material.
